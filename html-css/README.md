# Primeira Atividade – HTML e CSS

## Minha Perspectiva Sobre a Criação de Sites

Esta atividade tem como objetivo apresentar minha perspectiva sobre o desenvolvimento de sites utilizando HTML e CSS.

### Sobre o Projeto

O site foi desenvolvido como parte da primeira atividade prática de HTML e CSS, explorando conceitos básicos de estruturação e estilização de páginas web.

### Tecnologias Utilizadas

- **HTML5:** utilizado para estruturar o conteúdo da página.
- **CSS3:** utilizado para personalizar a aparência dos elementos.
- **GitHub Pages:** utilizado para hospedar o projeto.

### Objetivos de Aprendizado

- Entender a estrutura de documentos HTML.
- Conhecer diferentes elementos e suas funções.
- Desenvolver familiaridade com HTML e CSS.
- Praticar a organização e apresentação de informações.
- Melhorar meus conhecimentos em desenvolvimento web.
